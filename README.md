# YouTube Playlist Downloader (Dashboard Edition) 🚀

برنامج متطور وحديث لتحميل قوائم التشغيل (Playlists) والفيديوهات من يوتيوب بسهولة، مع واجهة مستخدم احترافية (Dashboard) توفر تحكماً كاملاً في كل خطوة.

## ✨ المميزات (Features)
* **نسخة جاهزة للتشغيل مباشرة (.exe):** ملف تنفيذي مستقل يعمل بدون الحاجة لتثبيت بايثون.
* **واجهة احترافية (Dashboard):** تصميم عصري مريح للعين مقسم إلى شريط تحكم جانبي وشاشة عرض واسعة.
* **التحميل الانتقائي (Selective Download):** جلب بيانات القائمة أولاً (`Fetch Info`)، ثم تحديد الفيديوهات المطلوبة فقط لتحميلها باستخدام (Checkboxes).
* **أعلى جودة (1080p & Audio Only):** دعم لتحميل الفيديوهات بأعلى جودة متوفرة، بالإضافة لخيار تحميل الصوت فقط (MP3).
* **دعم شامل للترجمة و الـ CC:** 
  - إمكانية تحميل الترجمة المرفوعة يدوياً والترجمة التلقائية (`Auto CC`).
  - إمكانية دمج الترجمة مباشرة داخل الفيديو (`Embed CC`) لتظهر كمسار ترجمة يمكنك تشغيله وإيقافه في مشغلات الفيديو كـ VLC.
  - تحديد اللغات المطلوبة (عربي + إنجليزي، عربي فقط، إنجليزي فقط، أو جميع اللغات).
* **دعم الصور المصغرة:** دمج الصورة المصغرة (Thumbnail) داخل الفيديو أو المقطع الصوتي.
* **استكمال التحميل (Resume Capability):** إذا انقطع الإنترنت أو أوقفت التحميل، يمكنك استكماله لاحقاً من نفس النقطة (بدون البدء من الصفر).
* **الذكاء وحفظ الإعدادات:** يحفظ البرنامج مجلد التحميل المفضل لديك وجودتك المختارة تلقائياً ليوفر وقتك في المرات القادمة.
* **متابعة دقيقة للتقدم:** يعرض السرعة (Speed)، الوقت المتبقي (ETA)، الحجم المقدر، وشريط تقدم لكل فيديو وللقائمة ككل.

## 💻 طريقة الاستخدام (How to Use)

### الخيار الأسهل: تشغيل النسخة التنفيذية (EXE) 🚀
يمكنك تشغيل البرنامج فوراً بدون تثبيت أي شيء عبر فتح الملف:
[YouTubeDownloader.exe](file:///e:/YouTube-Playlist-Downloader/YouTubeDownloader.exe)

### أو التشغيل عبر بايثون (Python Script):
1. **تثبيت المكتبات:**
   ```bash
   pip install yt-dlp customtkinter
   ```
2. **تشغيل البرنامج:**
   ```bash
   python youtube_downloader_gui.py
   ```

## 🛠️ أداة FFmpeg (مهمة لجودة 1080p ودمج الصوت والترجمة)
أداة FFmpeg تتيح دمج مسارات الفيديو والصوت والترجمة (`Embed CC`).
لتثبيتها بسهولة:
```bash
winget install Gyan.FFmpeg
```
*(أو يمكنك ببساطة وضع ملف `ffmpeg.exe` في نفس مجلد البرنامج وسيتعرف عليه تلقائياً!)*

## ⚠️ خطوات التحميل
1. **إدخال الرابط:** انسخ رابط قائمة التشغيل أو الفيديو وضعه في `Playlist URL`.
2. **ضبط الإعدادات والترجمة:** اختر الجودة، وفعل خيار `Download Subtitles (CC)` مع تحديد خيارات الدمج واللغة حسب رغبتك.
3. **جلب البيانات (Fetch Info):** اضغط على `1. Fetch Info`.
4. **التحديد والتحميل:** حدد الفيديوهات المطلوبة واضغط `2. Download Selected`.
