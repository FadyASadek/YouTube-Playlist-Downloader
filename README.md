# دليل تشغيل برنامج YouTube Playlist Downloader

هذا البرنامج تمت كتابته بلغة Python ويحتاج لبعض المكتبات البسيطة لكي يعمل.
اتبع الخطوات التالية لتشغيله على جهازك:

## 1. المتطلبات الأساسية
تأكد من وجود **Python** على جهازك (يفضل إصدار 3.10 أو أحدث).
يمكنك تحميله من [موقع بايثون الرسمي](https://www.python.org/downloads/).

## 2. تثبيت المكتبات المطلوبة
افتح موجه الأوامر (CMD) أو (PowerShell) وانسخ هذا الأمر لتثبيت المكتبات الخاصة بواجهة المستخدم والتحميل:

```bash
pip install yt-dlp customtkinter
```

## 3. تثبيت أداة FFmpeg (مهم جداً لجودة 1080p والصوتيات)
لتحميل الفيديوهات بجودة 1080p أو استخراج الصوت كملف MP3، يجب تثبيت أداة `FFmpeg`.
- **أسهل طريقة لمستخدمي ويندوز**: افتح الـ CMD واكتب الأمر التالي:
  ```bash
  winget install Gyan.FFmpeg
  ```
  *(بعد اكتمال التثبيت، يجب إغلاق الـ CMD وإعادة فتحه، أو إعادة تشغيل الكمبيوتر لضمان قراءة النظام له).*
- **بدون FFmpeg**: سيعمل البرنامج بشكل طبيعي، ولكن أقصى جودة ستتمكن من تحميلها كملف واحد هي **720p**.

## 4. تشغيل البرنامج
بعد تثبيت المكتبات، اذهب إلى المجلد الذي يحتوي على ملف `youtube_downloader_gui.py`.
افتح الـ CMD في هذا المجلد واكتب:

```bash
python youtube_downloader_gui.py
```

سيفتح لك البرنامج واجهته الرسومية، ويمكنك لصق الرابط والبدء بالتحميل فوراً!
