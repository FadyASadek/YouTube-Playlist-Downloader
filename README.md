# YouTube Playlist Downloader (Dashboard Edition) 🚀

برنامج متطور وحديث لتحميل قوائم التشغيل (Playlists) والفيديوهات من يوتيوب بسهولة، مع واجهة مستخدم احترافية (Dashboard) توفر تحكماً كاملاً في كل خطوة.

## ✨ المميزات (Features)
* **واجهة احترافية (Dashboard):** تصميم عصري مريح للعين مقسم إلى شريط تحكم جانبي وشاشة عرض واسعة.
* **التحميل الانتقائي (Selective Download):** جلب بيانات القائمة أولاً (`Fetch Info`)، ثم تحديد الفيديوهات المطلوبة فقط لتحميلها باستخدام (Checkboxes).
* **أعلى جودة (1080p & Audio Only):** دعم لتحميل الفيديوهات بأعلى جودة متوفرة، بالإضافة لخيار تحميل الصوت فقط (MP3).
* **دعم الترجمة والصور المصغرة:** إمكانية تحميل الترجمة (عربي/إنجليزي) ودمج الصورة المصغرة (Thumbnail) داخل الفيديو أو المقطع الصوتي.
* **استكمال التحميل (Resume Capability):** إذا انقطع الإنترنت أو أوقفت التحميل، يمكنك استكماله لاحقاً من نفس النقطة (بدون البدء من الصفر).
* **الذكاء وحفظ الإعدادات:** يحفظ البرنامج مجلد التحميل المفضل لديك وجودتك المختارة تلقائياً ليوفر وقتك في المرات القادمة.
* **متابعة دقيقة للتقدم:** يعرض السرعة (Speed)، الوقت المتبقي (ETA)، الحجم المقدر، وشريط تقدم لكل فيديو وللقائمة ككل.

## 🛠️ المتطلبات وطريقة التثبيت (Installation)

هذا البرنامج تمت كتابته بلغة Python ويحتاج لبعض المكتبات لكي يعمل. اتبع الخطوات التالية:

### 1. تثبيت بايثون والمكتبات الأساسية
يجب أن يكون لديك [Python](https://www.python.org/downloads/) مثبت على جهازك. 
افتح موجه الأوامر (CMD) أو (PowerShell) واكتب الأمر التالي لتثبيت المكتبات المطلوبة:
```bash
pip install yt-dlp customtkinter
```

### 2. تثبيت أداة الدمج FFmpeg (هام جداً!)
أداة FFmpeg **ضرورية جداً** إذا كنت ترغب في:
- تحميل الفيديوهات بجودة **1080p**.
- تحميل المقاطع كـ **Audio Only (MP3)**.
- دمج الصورة المصغرة (Embed Thumbnail).

لتثبيتها بسهولة على أنظمة ويندوز، افتح الـ CMD واكتب الأمر التالي:
```bash
winget install Gyan.FFmpeg
```
*(ملاحظة: بعد انتهاء التثبيت، يجب إغلاق الـ CMD أو أي نافذة مفتوحة للبرنامج وإعادة تشغيلها ليتعرف الويندوز على FFmpeg).*

## 💻 طريقة الاستخدام (How to Use)

1. **تشغيل البرنامج:** افتح مسار الملف في الـ CMD واكتب:
   ```bash
   python youtube_downloader_gui.py
   ```
2. **إدخال الرابط:** انسخ رابط قائمة التشغيل (Playlist) أو الفيديو وضعْه في حقل `Playlist URL`.
3. **ضبط الإعدادات:** اختر الجودة المطلوبة ومسار الحفظ (Save Directory).
4. **جلب البيانات (Fetch Info):** اضغط على زر `1. Fetch Info` للاتصال بيوتيوب واستخراج أسماء الفيديوهات.
5. **التحديد والتحميل:** حدد الفيديوهات التي تريدها من القائمة، ثم اضغط على `2. Download Selected` ليبدأ التحميل!

## ⚠️ ملاحظات هامة
* **ملفات `.part`:** إذا توقف التحميل في المنتصف، ستلاحظ وجود ملفات تنتهي بـ `.part` في المجلد. **لا تقم بمسحها!** هذه الملفات تسمح للبرنامج باستكمال التحميل من النقطة التي توقف عندها عند المحاولة مرة أخرى.
* إذا ظهر لك خطأ `FFmpeg is not installed`، فهذا يعني أنك اخترت جودة 1080p أو MP3 أو Thumbnail والبرنامج لم يعثر على FFmpeg في جهازك. تأكد من الخطوة رقم 2.
